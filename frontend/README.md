# Project 3D - Frontend Service

Interactive scroll-driven 3D landing page interface.

## Features
- Direct mouse scroll scrubbing with Dual-LERP RAF engine
- Scrollytelling narrative overlay (Chapters 01 - 05)
- Glassmorphic telemetry HUD (FPS, coords, rotation angle, buffer indicators)
- Connects to backend on `http://localhost:5000` with graceful fallback
- Real-time pre-order inquiry submission

## Run

```bash
npm start
# Runs by default on http://localhost:3000
```
